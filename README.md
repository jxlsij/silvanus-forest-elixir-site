# SILVANUS Forest Elixir

A cinematic Next.js scrollytelling landing page for SILVANUS Forest Elixir Eau de Parfum.

The core interaction is a sticky, scroll-linked HTML canvas sequence: a green glass perfume bottle fractures, detonates, and disperses into glass, amber liquid, pine cones, and needles.

## Local Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.
